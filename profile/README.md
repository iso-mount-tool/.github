# WinCDEmu - A Letter for an Image You Have

## Needle

One image file on disk.
A free drive letter.
You know what the image is supposed to be.
You can unmount it from the same menu.

## Green

The letter appears.
You can open it and see the files you expected.
Unmount removes the letter.
The image file itself is unchanged.

## Yellow

The letter appeared and the contents look like the wrong disc. You mounted a different file. Unmount and check the name.
Windows asks to format the new letter. Do not format it. An image of an installer often looks odd. Cancel.
A second image wants the same letter. Unmount the first or pick another letter.
Autorun wants to launch a setup. You can decline. Mounting is not installing.

## Red

The file will not mount. It is incomplete, or it is not an image this build accepts. Do not "repair" it with a format of your real disk.
A guide tells you to disable security so the image will mount. Stop.
The image is not yours to use. Unmount and delete it if you should not have it. The tool will not grant the right.
You pointed the mount at a system disk by mistake in some other utility. This tool adds a letter. It should not erase your drive. If another window asked to format, you cancel.

## Tap

Right-click the image and mount, or use the menu the install added.
Open the letter.
Read one file so you know it is the right image.
Unmount.

## Logged

Image name.
Letter.
Whether you unmounted.
What the image was for, in a few words. Not a claim that you own something you do not.

## Idling

No leftover letters.
The image stays a file.
Autorun not required.
The driver the tool installed is for mounting. You do not need a second virtual-drive suite.

## Not this dial

This does not write a USB installer. A media writer does that, to a stick you chose.
It does not burn an optical disc.
It does not check a publisher hash. Do that before you mount, if the publisher posted one.
A virtual machine is a different kind of virtual disk.
Mounting a game image you do not own is not a feature.

## Next glance

The same image mounts again after a reboot if you ask it to. It should not return by surprise if you unmounted.
After a Windows update, mount one known image.
If the letter collides with a card reader, pick a later letter.
Keep one mounting tool. Two drivers for the same job fight.

## Panel off

Unmount.
The letter is gone from Explorer.
The image file remains where you stored it.
Uninstall if you no longer mount images. Your real disks stay.
Do not leave a mounted installer in a shared session.

## Someone else's panel

Their ISO is not yours to mount because it was on a shared drive.
A lab PC gets the tool only if the lab asked.
Do not mount an image and leave the letter for the next class.
Work policy may forbid extra drivers. If it does, do not install.
